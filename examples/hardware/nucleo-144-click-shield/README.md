# NUCLEO-144 Click Shield

This directory contains the KiCad project for the NUCLEO-144 Click Shield, a hardware add-on board designed to attach mikroBus click boards to an STM32 NUCLEO-144 development board. This clicks shield is useful to run various Open1722 examples for Zephyr on a modular platform.

## Use

Open the `.kicad_pro` file in KiCad to work with the project. From there you can edit the schematic, update the PCB layout, and regenerate fabrication outputs.

If you need a stable reference for the released design, use the files in `v1.1/`.
